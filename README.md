# LoL Overlay

리그 오브 레전드 게임 화면 위에 정보를 띄워 주고 음성으로 알려 주는 데스크톱 앱입니다.

## 다운로드

**[최신 버전 받기](https://github.com/leesce10/lol-overlay-releases/releases/latest)**

- Windows: `LoL-Overlay-Setup.exe`
- macOS: `LoL-Overlay-Setup.dmg`

## 기능

- **게임 시작 브리핑**: 상대 티어·챔피언 숙련도와 내 라인 상대법을 음성으로 알려 줍니다.
- **적 아이템 알림**: 상대가 핵심 아이템을 완성하면 화면과 음성으로 알려 줍니다.
- **적 라인 복귀 타이머**: 내 라인 상대가 죽으면 라인에 돌아올 때까지 남은 시간을 보여 주고, 복귀 5초 전에 알려 줍니다.
- **오브젝트 타이머**: 유충·전령·드래곤·바론이 나오기 60초 전부터 카운트다운과 함께 지금 싸우면 유리한지 불리한지 알려 줍니다.

## 설치와 사용

1. 설치 파일을 받아 실행합니다.
   - Windows에서 "Windows의 PC 보호" 창이 뜨면 **추가 정보 → 실행**을 누릅니다. 아직 코드 서명이 없어서 나오는 경고입니다.
2. 설치가 끝나면 앱이 트레이(작업 표시줄 오른쪽 아래)에서 조용히 대기합니다.
3. 롤 게임에 들어가면 자동으로 동작합니다. 따로 누를 것은 없습니다.

**롤 화면 모드를 "테두리 없음" 또는 "창 모드"로 설정해야 합니다.** 전체 화면에서는 오버레이가 보이지 않습니다. (롤 설정 → 비디오 → 화면 모드)

소환사의 협곡 일반·랭크 게임에서만 동작합니다. 칼바람, 아레나, 관전에서는 동작하지 않습니다.

## 설정

트레이 아이콘을 우클릭해 **설정**을 누르거나, 게임 화면 왼쪽 위의 톱니 버튼을 누릅니다.

- 기능마다 화면 표시와 음성을 따로 켜고 끌 수 있습니다.
- 말투(반말/존댓말), 목소리, 볼륨을 바꿀 수 있습니다.
- 알림 위치와 크기를 조절할 수 있습니다. 값을 움직이면 샘플 알림이 화면에 나타납니다.
- 컴퓨터를 켤 때 자동으로 실행되게 할 수 있습니다.

## 업데이트

새 버전이 나오면 앱이 알아서 받아 두고 설치할지 묻습니다. 게임 중에는 묻지 않습니다.

## 자주 묻는 질문

**오버레이가 안 보여요.**
롤 화면 모드가 "전체 화면"이면 보이지 않습니다. "테두리 없음"으로 바꿔 주세요. 그리고 트레이에 LoL Overlay 아이콘이 있는지 확인해 주세요.

**안전한가요? 제재 대상이 아닌가요?**
롤 클라이언트가 공식적으로 제공하는 로컬 데이터(Live Client Data API)만 읽습니다. 화면에 이미 보이는 정보만 사용하고, 게임 메모리를 읽거나 입력을 대신하지 않습니다.

**문제가 생겼어요.**
트레이 아이콘 우클릭 → **로그 폴더 열기**에서 `overlay.log` 파일을 보내 주시면 원인을 찾는 데 도움이 됩니다.
